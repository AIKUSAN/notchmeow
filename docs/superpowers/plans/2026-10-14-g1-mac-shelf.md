# G1-mac: The Shelf and Send in the macOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sub-project G1 on the Mac. A file dragged over the open notch lands in one of two halves: **Ask** (the left half, today's drop, unchanged) or **Shelf** (the right half, a tray). Files dropped on Shelf are parked in the notch: kept as links (security-scoped bookmarks, a copy only for a file that has no original), shown in a new island view, dragged out later to Finder, Mail, a chat or a terminal, asked about (a new chat), sent with the share sheet or AirDrop, shown in Finder, or removed. A small count sits at the right end of the compact island's wing while the shelf is not empty. The shelf opens from a drop, a menu-bar item, a click on the badge and an optional shortcut (off by default). It costs nothing while the island is hidden.

**Architecture:** The shared rules are a Swift port of the G1-0 contract (`ShelfRules`: `zoneAt`, `shelfClean`, `shelfAdd`, with a strict JSON reader of its own), replayed against `tests/fixtures/shelf/`. Storage is `ShelfStore` (Foundation only: `shelf.json`, one bookmark per item, copies in `shelf/<id>/`, the backup of an unreadable file) behind `ShelfModel` (what the view shows). The drop halves are **an additive layer**: the upload canvas stays the Ask half untouched and `ShelfDropLayer` draws the Shelf half over the right half of it; a render check proves the layer draws nothing left of the centre line and a script proves the canvas files did not change. `FileDropNSView` learns the half the pointer is over (`ShelfDrop.half`), accepts promised files and browser images only over Shelf, and ignores a drag that started inside the app; a Shelf drop goes through `ShelfDropReader` and `ShelfFlow` and never through `FileDropHandler.handle`, so it does not wait for the desktop cat and clears the file alert. Dragging out is an AppKit drag session started from the tile; while it runs, and while the share picker is up, the island is held open by `AppState.shelfHoldsIsland` (the state machine's `isHeldOpen` and the poll's `inIsland`), where the picker's hold is a clock reading with a limit, so no timer exists. The badge is drawn by `IslandContainer` beside the wing's grid and fades with it. A per-cat hit test hook is left for F1 and F1 is not built: the Shelf half and the Ask half are the only two meanings. Nothing is checked by launching the installed app: pictures come from `scripts/render-shelf.sh`, behaviour from `swiftc` test programs and source pins.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI, AppKit (`NSDraggingDestination`, `NSDraggingSource`, `NSFilePromiseReceiver`, `NSSharingServicePicker`, `NSSharingService`), Foundation security-scoped bookmarks, XcodeGen, `swiftc` test programs, Bash.

**Spec:** `docs/superpowers/specs/2026-10-04-file-shelf-transfer-design.md`, revision 2, **G1 only** (G2, the link between machines, is a later round and is not built here). The contract is G1-0's: `docs/SHELF-CONTRACT.md` and `tests/fixtures/shelf/` (`zone-cases.json`, `shelf-cases.json`, `reference.py`, `build_cases.py`). The format and the Mac code's conventions are H-mac's (`docs/superpowers/plans/2026-10-12-h-mac-desktop-cat.md`) and fixes-after-h's (`docs/superpowers/plans/2026-10-13-fixes-after-h.md`). The Windows and Linux twin is a separate plan (G1-tauri); "Parity" below says where the two differ.

**Base:** a new branch `g1/mac-shelf` in a git worktree, from `notchmeow/rebrand` at **`619b407` or later** (`git merge-base --is-ancestor 619b407 HEAD` must succeed): G1-0 is merged, `fixes/after-h` is merged (the file catch and the two-cats fix are in the drop path this plan builds on), and the wardrobe contract (I-0) is merged and not used. This plan never edits `design/prototype/cat-core.js`, a fixture of `tests/fixtures/`, `shared/theme.json`, a generated theme file, `UploadCanvasView.swift`, `UploadSequenceEngine.swift`, `UploadCatDriver.swift`, `CatFileRule.swift` or anything under `windows/`.

## Global Constraints

Every task's requirements include this section. Values are copied from the spec and from G1-0's contract; the lines marked "(plan decision)" are choices this plan makes where the spec is silent, and are listed again under "Open questions for the owner".

- **Swift 6, SwiftUI and AppKit, no third-party dependencies.** The pure files (`ShelfRules`, `ShelfStore`, `ShelfModel`, `ShelfDrop`, `ShelfBadge`) stay Foundation (and CoreGraphics, Combine) only and carry no build condition; `ShelfStore` is the only shelf file with a build condition (`#if APPSTORE`, for the bookmark option).
- **0 % CPU when the island is hidden, and no polling of its own.** No new `Timer`, `DispatchSourceTimer`, display link, `asyncAfter`, `NSEvent` monitor or `setInterval`. Whether a file still exists is asked **only when the shelf opens** (`ShelfModel.refresh`). The share picker's hold-open is a clock reading with a limit (`ShelfHold`, 120 s), evaluated when the poll or the state machine asks; the hold for a drag out is a flag that the drag session's own end clears. The badge is drawn by the view that already exists. `scripts/test-shelf-wiring.sh` pins the absence of all of these in the shelf's files.
- **Never restyle a shipping view.** The Ask half is the upload canvas as it ships (`scripts/check-ask-unchanged.sh`, `render-shelf.sh --ask-check`). Every edit to an existing file is listed in "File Structure" and is additive: a layer inside the upload branch, a case in `IslandView` and its layout entry, a switch case, `isTall` for the new view, the badge after the grid, wider drag types and a guard in `FileDropNSView`, a menu item, the shortcut action. The wing's rules (`IslandWing`) and their call sites are untouched (the wing test's pinned lines stay as they are).
- **Frozen values.** The shortcut action ID **`shelf`** (appended last in `ShortcutAction`: Carbon identifies a hot key by its index in `allCases`; ⌃⌥S; off by default; in the App Store build too), the island view case `shelf`, the marker strings `NM_SHELF_STORE_ACTIVE` (every build) and `NM_SHELF_DEV_PANEL` (Debug only), pill IDs, cat IDs, display mode IDs, the contract strings (`nm-hook`, `nm.sock`, `nm_kind`, `nm_agent`) and the bundle identifiers. The shelf's files are `shelf.json`, `shelf.json.bad-<ms>` and `shelf/<id>/<name>` in `HookServer.supportDir`; **the shelf is never the inbox** (Ask's copy still goes to `inbox`, which overwrites by name).
- **The contract decides.** `ShelfRules` is replayed against both fixtures by `scripts/test-shelf-rules.sh`; `tests/fixtures/shelf/reference.py` is the tie-breaker. A shelf holds **30** items; reading `shelf.json` keeps the 30 newest, but **a drop never evicts**: it refuses the extras (`full`) and the app says so. A name is 1 to 255 code points with none of the characters the contract refuses; the id is also the name of the item's folder under `shelf/`; a link is the base64 of a bookmark; sizes and times are whole numbers up to 2^53 - 1.
- **Originals are never touched.** Remove deletes a copy's folder and nothing else; no button moves, renames or deletes a linked file (a source pin proves it). An unreadable or partly unreadable `shelf.json` is copied to `shelf.json.bad-<ms>` before the first write over it.
- **Security and privacy.** A Shelf drop never fetches a URL (no `URLSession`, no `NSImage` read from the pasteboard: image data is read as raw PNG or TIFF bytes). The log says only that a send started (`appendAppLog("shelf.log", "a send started")`): no name, no count, no recipient. The OS share sheet keeps recipients private from NotchMeow. No telemetry, no network. Sending always starts with a user click.
- **The desktop cat and the file alert.** A Shelf drop does not wait for the desktop cat (it never calls `FileDropHandler.handle`) and clears the file-drag alert; the desktop cat, if it was flying in to catch the file, goes back by its normal rule.
- **The compact badge never wakes a hidden island.** It is drawn only while the island is `compact`, with something on the shelf, and not during the greeting's tail; it fades with the wing; nothing in the shelf calls `fsm.reveal` or posts `hookExpand` for the count.
- **Coordinates and units.** Points; the island is 640 wide when open (`IslandConst.expandedWidth`); the halves are measured from the island's left edge at the drag's own location (`windowToIsland`).
- **Never edit `NotchBuddy.xcodeproj` by hand.** A task that adds a Swift file to the app runs `cd NotchBuddy && xcodegen` before it builds and commits the regenerated `project.pbxproj`. A new Swift file that a test or render script compiles is added to that script's list.
- **No `UserDefaults` suite, and no write to `UserDefaults.standard` or `~/Library`, in any test or script.** Tests build a `ShelfStore` on a folder under `NM_LOG_DIR`'s parent (a temp folder); the shortcut tests use their own `MemoryStore`.
- **Nothing of Coucou's comes back**, and the names Coucou and Mochi appear in no new code (`scripts/check-no-leftovers.sh` must stay green). No sound is added.
- **Models and commits** (CLAUDE.md, "Working with AI agents", 2026-10-12): Haiku 5.5 first, Sonnet 5.5 only on a named trigger, never Opus or Fable. Each commit is local only, never pushed, lists only the files its task names, and ends with the `Co-Authored-By` line of the model that did the task: `Claude Haiku 5.5` for `nm-implementer-light` and `nm-implementer`, `Claude Sonnet 5.5` for `nm-implementer-deep`.

## Review Focus

The spec says what the shelf does. It is silent on these inputs and conditions, and each would bite a person first, most likely first. Each line names the test that pins it.

1. **A drag that is not a file.** A link or text dragged from a browser, an image dragged out of a page, a promised file from Mail or Photos. Expected: the island opens only for a drag that carries something the app can use, a web URL is never fetched or turned into a file, a promised file or an image is accepted over Shelf only and refused over Ask exactly as before, and a failed promise adds nothing. Tests: Task 3 (`ShelfDrop.accepts`, `opensIsland`), Task 5 (the reader's pins: no `URLSession`, no `NSImage` read, raw PNG or TIFF bytes only).
2. **The same file twice, and a drag that comes home.** A file dropped twice (two bookmarks of it are not the same bytes), dropped twice in one drop, or dragged out of the shelf and back onto the island. Expected: one item, the second is a duplicate with a short note, and a drag that started inside the app is never added. Tests: Task 2 (path duplicates, same drop twice), Task 5 (`isOwnDrag` at all three steps).
3. **An original that moved, was deleted or sits on an unmounted disk, and a stale bookmark.** Expected: the tile says Missing, only Remove works on it, the original is never touched, a stale bookmark is renewed when the file is opened, and nothing checks in the background. Tests: Task 2 (missing, remove a link, remove a copy, a restart), Task 4 (the Missing tile), Task 8 (`ShelfActionRules`).
4. **A hostile or half-written `shelf.json`.** A byte order mark, a truncated file, invalid UTF-8, a list nested 10 000 deep, 300 items, lone surrogates, names such as `CON` or `../x`. Expected: reading never traps and gives an empty or a trimmed shelf, and the first write after an unreadable or lossy read keeps the old file as `shelf.json.bad-<ms>`. Tests: Task 1 (the 18 parse cases, 132 clean cases and the parser's own), Task 2 (the backup rule, a clean file never backed up).
5. **The island folding under the user, or never folding.** The pointer leaves the island during a drag out, the share picker is open, a delegate callback never arrives, the drag ends outside the island. Expected: the island stays while the drag runs and while the picker is up, a hold older than 120 s is ignored, and a drag that ends outside the island ends in the ordinary mouse-left so the fold timer starts. Tests: Task 7 (`ShelfHold`, the pins on `isHeldOpen` and `inIsland`), Task 9 (every way out of a share clears the hold).

**A hook point left for F1 (not built).** F1 (dropping a file on a cat hands it to that cat's agent) will add its meaning to the Ask half, not a third half. This plan adds no cat hit test, no type and no setting for it.

**Parity with Windows/Linux (G1-tauri), and what differs.** The three rules are the same (the fixtures). The Mac adds: promised files and browser images over Shelf (the Windows and Linux drop event carries paths only), drag out through AppKit (Windows uses OLE, Linux GTK, with a spike first), Send through `NSSharingServicePicker` and AirDrop (Windows the Share window, Linux Show in folder), the menu-bar item (a tray item there), the optional `shelf` shortcut (the Windows and Linux app has no global shortcuts), scoped bookmarks in the App Store build, and the Debug panel (`?dev` there).

**App Store build.** The whole shelf is in it. The Debug panel is compiled out of Release and App Store builds, and `scripts/check-app-binary.sh` proves both markers.

```swift
import Foundation

// The shelf contract on the Mac (sub-project G1; docs/SHELF-CONTRACT.md, tests/fixtures/shelf/): the three rules both apps share, `zoneAt` (which half of the open island the pointer is
// in), `shelfClean` (how shelf.json is read) and `shelfAdd` (files dropped on the Shelf half), and the strict JSON reader the file goes through. Foundation only, no AppKit. The fixtures are
// replayed by scripts/test-shelf-rules.sh; `tests/fixtures/shelf/reference.py` decides when this file and a fixture disagree.

// MARK: - A JSON value, read the way the contract reads it

/// A parsed JSON value. Foundation's `JSONSerialization` cannot be used: it repairs a lone surrogate, may strip a byte order mark and has its own idea of big numbers. A string remembers
/// whether it held a lone surrogate (`lone`), which no Swift `String` can hold and which the contract refuses in a name and in a link.
indirect enum ShelfJSON: Equatable, Sendable {
    case null
    case bool(Bool)
    case number(Double)
    case string(String, lone: Bool)
    case array([ShelfJSON])
    case object([String: ShelfJSON])

    static func text(_ s: String) -> ShelfJSON { .string(s, lone: false) }
}

enum ShelfJSONParser {
    /// Nesting deeper than this is "not a shelf" (Python's reference gives up at about 1000 levels; a shelf is two deep).
    static let maxDepth = 512

    /// The bytes of a file to the value they hold, or nil when they are not strict JSON: invalid UTF-8, a byte order mark in front, `NaN`, `Infinity`, text after the value, a control
    /// character inside a string, a number with a leading zero. The last of a repeated key wins.
    static func parse(_ bytes: [UInt8]) -> ShelfJSON? {
        let text = String(decoding: bytes, as: UTF8.self)
        guard Array(text.utf8) == bytes else { return nil }   // decoding repairs invalid UTF-8 with U+FFFD, which changes the bytes
        var p = Reader(s: Array(text.unicodeScalars))
        guard let v = p.value(depth: 0) else { return nil }
        p.skipWhite()
        return p.i == p.s.count ? v : nil
    }

    private struct Reader {
        let s: [Unicode.Scalar]
        var i = 0

        init(s: [Unicode.Scalar]) { self.s = s }

        mutating func skipWhite() {
            while i < s.count, s[i] == " " || s[i] == "\t" || s[i] == "\n" || s[i] == "\r" { i += 1 }
        }

        mutating func lit(_ word: String, _ v: ShelfJSON) -> ShelfJSON? {
            let w = Array(word.unicodeScalars)
            guard i + w.count <= s.count, Array(s[i..<i + w.count]) == w else { return nil }
            i += w.count
            return v
        }

        mutating func value(depth: Int) -> ShelfJSON? {
            skipWhite()
            guard i < s.count else { return nil }
            switch s[i] {
            case "{": return object(depth: depth + 1)
            case "[": return array(depth: depth + 1)
            case "\"": return string().map { .string($0.text, lone: $0.lone) }
            case "t": return lit("true", .bool(true))
            case "f": return lit("false", .bool(false))
            case "n": return lit("null", .null)
            default: return number()
            }
        }

        mutating func array(depth: Int) -> ShelfJSON? {
            guard depth <= ShelfJSONParser.maxDepth else { return nil }
            i += 1
            var out: [ShelfJSON] = []
            skipWhite()
            if i < s.count, s[i] == "]" { i += 1; return .array(out) }
            while true {
                guard let v = value(depth: depth) else { return nil }
                out.append(v)
                skipWhite()
                guard i < s.count else { return nil }
                if s[i] == "," { i += 1; continue }
                if s[i] == "]" { i += 1; return .array(out) }
                return nil
            }
        }

        mutating func object(depth: Int) -> ShelfJSON? {
            guard depth <= ShelfJSONParser.maxDepth else { return nil }
            i += 1
            var out: [String: ShelfJSON] = [:]
            skipWhite()
            if i < s.count, s[i] == "}" { i += 1; return .object(out) }
            while true {
                skipWhite()
                guard i < s.count, s[i] == "\"", let key = string() else { return nil }
                skipWhite()
                guard i < s.count, s[i] == ":" else { return nil }
                i += 1
                guard let v = value(depth: depth) else { return nil }
                out[key.text] = v
                skipWhite()
                guard i < s.count else { return nil }
                if s[i] == "," { i += 1; continue }
                if s[i] == "}" { i += 1; return .object(out) }
                return nil
            }
        }

        func hex4(_ at: Int) -> UInt32? {
            guard at + 4 <= s.count else { return nil }
            var v: UInt32 = 0
            for k in 0..<4 {
                guard let d = Character(s[at + k]).hexDigitValue else { return nil }
                v = v * 16 + UInt32(d)
            }
            return v
        }

        mutating func string() -> (text: String, lone: Bool)? {
            i += 1
            var out = String.UnicodeScalarView()
            var lone = false
            while i < s.count {
                let c = s[i]
                if c == "\"" { i += 1; return (String(out), lone) }
                if c.value < 0x20 { return nil }
                if c != "\\" { out.append(c); i += 1; continue }
                i += 1
                guard i < s.count else { return nil }
                let e = s[i]
                i += 1
                switch e {
                case "\"": out.append("\"")
                case "\\": out.append("\\")
                case "/": out.append("/")
                case "b": out.append("\u{8}")
                case "f": out.append("\u{c}")
                case "n": out.append("\n")
                case "r": out.append("\r")
                case "t": out.append("\t")
                case "u":
                    guard let u = hex4(i) else { return nil }
                    i += 4
                    if (0xD800...0xDBFF).contains(u) {
                        // A high surrogate pairs with an escaped low one right after it; on its own it is lone.
                        if i + 6 <= s.count, s[i] == "\\", s[i + 1] == "u", let lo = hex4(i + 2), (0xDC00...0xDFFF).contains(lo) {
                            i += 6
                            out.append(Unicode.Scalar(0x10000 + ((u - 0xD800) << 10) + (lo - 0xDC00))!)
                        } else {
                            lone = true
                        }
                    } else if (0xDC00...0xDFFF).contains(u) {
                        lone = true
                    } else {
                        out.append(Unicode.Scalar(u)!)
                    }
                default: return nil
                }
            }
            return nil
        }

        mutating func number() -> ShelfJSON? {
            let start = i
            if i < s.count, s[i] == "-" { i += 1 }
            func digits() -> Int {
                var n = 0
                while i < s.count, s[i].value >= 0x30, s[i].value <= 0x39 { i += 1; n += 1 }
                return n
            }
            guard i < s.count else { return nil }
            if s[i] == "0" { i += 1 } else if digits() == 0 { return nil }
            if i < s.count, s[i] == "." {
                i += 1
                if digits() == 0 { return nil }
            }
            if i < s.count, s[i] == "e" || s[i] == "E" {
                i += 1
                if i < s.count, s[i] == "+" || s[i] == "-" { i += 1 }
                if digits() == 0 { return nil }
            }
            var text = String.UnicodeScalarView()
            text.append(contentsOf: s[start..<i])
            guard let d = Double(String(text)) else { return nil }   // 1e400 is +infinity, which the rules treat as "not a number we keep"
            return .number(d)
        }
    }
}

// MARK: - The items

/// Which half of the open island the pointer is in.
enum ShelfZone: String, Sendable { case ask, shelf }

/// One word for each incoming item of a drop (`shelfAdd`).
enum ShelfAddResult: String, Sendable { case added, duplicate, full, invalid }

/// A parked file. `link` is the base64 of a security-scoped bookmark (a link) and is nil for a copy, which lives in `shelf/<id>/<name>`.
struct ShelfItem: Equatable, Sendable {
    var id: String
    var name: String
    var size: Int64
    var folder: Bool
    var copy: Bool
    var link: String?
    var addedAt: Int64

    /// The item as the contract's JSON (what `shelfAdd` takes and what shelf.json holds).
    var json: ShelfJSON {
        var o: [String: ShelfJSON] = ["id": .text(id), "name": .text(name), "size": .number(Double(size)), "folder": .bool(folder), "copy": .bool(copy), "addedAt": .number(Double(addedAt))]
        if let link { o["link"] = .text(link) }
        return .object(o)
    }
}

enum ShelfRules {
    static let max = 30
    static let nameMax = 255
    static let linkMax = 8192
    /// The largest size and time every language holds exactly: 2^53 - 1.
    static let numberMax: Double = 9007199254740991

    // MARK: zoneAt

    /// `x` is the pointer's distance from the island's left edge, `width` the island's, both in points. The centre line belongs to Ask, the drop that exists today. Outside the island, or
    /// not a finite number within `numberMax`: nil (no half).
    static func zoneAt(x: Double, width: Double) -> ShelfZone? {
        guard x.isFinite, width.isFinite, Swift.abs(x) <= numberMax, Swift.abs(width) <= numberMax else { return nil }
        guard width > 0, x >= 0, x <= width else { return nil }
        return x * 2 <= width ? .ask : .shelf
    }

    /// The fixture's form: either side may be missing, text, `null` or a boolean, which are refused.
    static func zoneAt(x: ShelfJSON?, width: ShelfJSON?) -> ShelfZone? {
        guard case .number(let a)? = x, case .number(let b)? = width else { return nil }
        return zoneAt(x: a, width: b)
    }

    // MARK: Names, ids and links

    private static let reservedNames: Set<String> = {
        var s: Set<String> = ["CON", "PRN", "AUX", "NUL", "COM\u{B9}", "COM\u{B2}", "COM\u{B3}", "LPT\u{B9}", "LPT\u{B2}", "LPT\u{B3}"]
        for n in 1...9 { s.insert("COM\(n)"); s.insert("LPT\(n)") }
        return s
    }()

    /// A Windows device name as the stem of `s` (the part before the first dot, trailing spaces trimmed), ASCII case-insensitively.
    static func reserved(_ s: String) -> Bool {
        var stem = Array(s.unicodeScalars.prefix { $0 != "." })
        while stem.last == " " { stem.removeLast() }
        var up = String.UnicodeScalarView()
        for c in stem { up.append(c.value >= 0x61 && c.value <= 0x7A ? Unicode.Scalar(c.value - 32)! : c) }
        return reservedNames.contains(String(up))
    }

    private static func isIdScalar(_ c: Unicode.Scalar) -> Bool {
        (c.value >= 0x30 && c.value <= 0x39) || (c.value >= 0x41 && c.value <= 0x5A) || (c.value >= 0x61 && c.value <= 0x7A) || c == "_" || c == "-"
    }

    /// 1 to 255 code points; no control, format, separator or lone surrogate; no `/` or `\`; not only dots; not ending in a dot or a space; not a device name.
    static func nameOK(_ name: String, lone: Bool) -> Bool {
        let scalars = Array(name.unicodeScalars)
        guard !lone, (1...nameMax).contains(scalars.count) else { return false }
        for c in scalars {
            switch c.properties.generalCategory {
            case .control, .format, .surrogate, .lineSeparator, .paragraphSeparator: return false
            default: break
            }
            if c == "/" || c == "\\" { return false }
        }
        if scalars.allSatisfy({ $0 == "." }) || scalars.last == "." || scalars.last == " " { return false }
        return !reserved(name)
    }

    /// 1 to 8192 code points, no C0, DEL or C1 control, no lone surrogate. A link is never shown, so the name rules do not apply.
    static func linkOK(_ link: String, lone: Bool) -> Bool {
        let scalars = Array(link.unicodeScalars)
        guard !lone, (1...linkMax).contains(scalars.count) else { return false }
        return !scalars.contains { $0.value < 0x20 || ($0.value >= 0x7F && $0.value <= 0x9F) }
    }

    /// A whole number from 0 to `numberMax` (`5` and `5.0` are the same number), else 0.
    static func whole(_ v: ShelfJSON?) -> Int64 {
        guard case .number(let d)? = v, d.isFinite, d == d.rounded(.towardZero), d >= 0, d <= numberMax else { return 0 }
        return Int64(d)
    }

    // MARK: shelfClean

    /// One stored item to its clean form, or nil when it cannot be kept.
    static func cleanItem(_ raw: ShelfJSON) -> ShelfItem? {
        guard case .object(let o) = raw else { return nil }
        guard case .string(let id, let idLone)? = o["id"], !idLone, (1...64).contains(id.unicodeScalars.count), id.unicodeScalars.allSatisfy(isIdScalar), !reserved(id) else { return nil }
        guard case .string(let name, let nameLone)? = o["name"], nameOK(name, lone: nameLone) else { return nil }
        let copy = o["copy"] == .bool(true), folder = o["folder"] == .bool(true)
        if copy && folder { return nil }   // a folder is only ever a link
        var link: String?
        if !copy {
            guard case .string(let l, let lLone)? = o["link"], linkOK(l, lone: lLone) else { return nil }
            link = l
        }
        return ShelfItem(id: id, name: name, size: whole(o["size"]), folder: folder, copy: copy, link: link, addedAt: whole(o["addedAt"]))
    }

    /// A link as its code points: Swift's `String` equality treats a precomposed and a decomposed é as one string, the contract does not.
    static func linkKey(_ link: String) -> [UInt32] { link.unicodeScalars.map(\.value) }

    /// Newest first (stable: equal times keep the file's order), then the first of each id (ASCII case-insensitively) and of each link (exactly), then the first 30. One pass in sorted
    /// order: an item skipped for a repeated link reserves nothing, so its id stays free.
    static func tidy(_ items: [ShelfItem]) -> [ShelfItem] {
        let sorted = items.enumerated().sorted { $0.element.addedAt != $1.element.addedAt ? $0.element.addedAt > $1.element.addedAt : $0.offset < $1.offset }.map(\.element)
        var ids = Set<String>(), links = Set<[UInt32]>(), out: [ShelfItem] = []
        for it in sorted {
            if ids.contains(it.id.lowercased()) || (it.link.map { links.contains(linkKey($0)) } ?? false) { continue }
            ids.insert(it.id.lowercased())
            if let l = it.link { links.insert(linkKey(l)) }
            out.append(it)
        }
        return Array(out.prefix(max))
    }

    /// The parsed content of shelf.json to the items the shelf holds. Anything that is not `{"items": [ ... ]}` is an empty shelf. Never traps.
    static func clean(_ raw: ShelfJSON?) -> [ShelfItem] {
        guard case .object(let o)? = raw, case .array(let list)? = o["items"] else { return [] }
        return tidy(list.compactMap(cleanItem))
    }

    // MARK: shelfAdd

    /// Files dropped on the Shelf half. `items` is the shelf as stored (cleaned first), `incoming` the drop's items in the order the app wants them shown. One word per incoming item;
    /// nothing already on the shelf is ever removed.
    static func add(items: ShelfJSON?, incoming: ShelfJSON?) -> (items: [ShelfItem], results: [ShelfAddResult]) {
        var listed: [ShelfJSON] = []
        if case .array(let l)? = items { listed = l }
        let current = clean(.object(["items": .array(listed)]))
        var ids = Set(current.map { $0.id.lowercased() }), links = Set(current.compactMap { $0.link.map(linkKey) })
        var accepted: [ShelfItem] = [], results: [ShelfAddResult] = []
        var list: [ShelfJSON] = []
        if case .array(let l)? = incoming { list = l }
        for raw in list {
            guard let it = cleanItem(raw) else { results.append(.invalid); continue }
            if ids.contains(it.id.lowercased()) || (it.link.map { links.contains(linkKey($0)) } ?? false) {
                results.append(.duplicate)
            } else if current.count + accepted.count >= max {
                results.append(.full)
            } else {
                accepted.append(it)
                ids.insert(it.id.lowercased())
                if let l = it.link { links.insert(linkKey(l)) }
                results.append(.added)
            }
        }
        return (tidy(accepted + current), results)
    }

    /// The typed form the app uses: the stored shelf and the drop's items.
    static func add(_ items: [ShelfItem], _ incoming: [ShelfItem]) -> (items: [ShelfItem], results: [ShelfAddResult]) {
        add(items: .array(items.map(\.json)), incoming: .array(incoming.map(\.json)))
    }

    // MARK: Reading and writing the file

    /// The bytes of shelf.json to the items it holds. Unreadable bytes are an empty shelf.
    static func read(_ bytes: [UInt8]) -> [ShelfItem] { clean(ShelfJSONParser.parse(bytes)) }

    /// Whether reading `bytes` keeps everything in them: strict JSON, an object with a list of items, and no item dropped or removed as a duplicate. When it does not, an app that is
    /// about to write a new shelf.json keeps a copy of the old one first (docs/SHELF-CONTRACT.md).
    static func isLossless(_ bytes: [UInt8]) -> Bool {
        guard case .object(let o)? = ShelfJSONParser.parse(bytes), case .array(let list)? = o["items"] else { return false }
        return clean(.object(o)).count == list.count
    }

    /// shelf.json's bytes: `{"version": 1, "items": [ ... ]}`, keys sorted so the file is stable.
    static func encode(_ items: [ShelfItem]) -> Data {
        let objs: [[String: Any]] = items.map { it in
            var d: [String: Any] = ["id": it.id, "name": it.name, "size": it.size, "folder": it.folder, "copy": it.copy, "addedAt": it.addedAt]
            if let l = it.link { d["link"] = l }
            return d
        }
        return (try? JSONSerialization.data(withJSONObject: ["version": 1, "items": objs] as [String: Any], options: [.sortedKeys, .withoutEscapingSlashes])) ?? Data("{\"items\":[],\"version\":1}".utf8)
    }
}
```

**What the store does.** A link is the base64 of a bookmark (`.withSecurityScope` under `#if APPSTORE`, a plain bookmark in the GitHub build). Two bookmarks of one file are not the same bytes, so a re-dropped file is found by its resolved path (`heldPaths`) and answered `duplicate` before the contract's rule sees it. A copy is made only for `.temporary` and lives in `shelf/<id>/<name>`; a copy that was not added (full, invalid) is deleted again. Opening an item starts its security scope and renews a stale bookmark. `shelf.json` is read with `ShelfRules.read`, and when it holds something reading would lose (unreadable, or an item dropped or deduplicated: `!isLossless`) the **first** write keeps the old file as `shelf.json.bad-<ms>` (never overwritten). Nothing here runs in the background: `checkMissing` is asked when the shelf opens.

```swift
import Foundation

// The shelf's storage (sub-project G1): `shelf.json` (the list, read and written through ShelfRules), a security-scoped bookmark per item, and a copy under `shelf/<id>/<name>` only for a
// file that has no original (a promised file, a browser image). Originals are never touched. Foundation only; the App Store build asks for scoped bookmarks, the GitHub build is not
// sandboxed and uses plain ones through the same code. Nothing here runs in the background: whether a file still exists is asked when the shelf opens (`checkMissing`).

/// What a drop hands the store for each file.
enum ShelfIncoming {
    /// An original on disk: kept as a link (a folder too).
    case file(URL)
    /// A file with no original (a promised file, a browser image): copied into `shelf/<id>/`. The caller may delete its own copy afterwards.
    case temporary(URL)
}

/// A shelf item opened for use: its file, and the security scope that keeps it readable until `end()`.
final class ShelfAccess {
    let url: URL
    private var scoped: Bool
    init(url: URL, scoped: Bool) { self.url = url; self.scoped = scoped }
    func end() {
        guard scoped else { return }
        scoped = false
        url.stopAccessingSecurityScopedResource()
    }
    deinit { if scoped { url.stopAccessingSecurityScopedResource() } }
}

final class ShelfStore {
    #if APPSTORE
    static let isAppStoreBuild = true
    #else
    static let isAppStoreBuild = false
    #endif

    let support: URL
    private(set) var items: [ShelfItem] = []
    /// Why the last write failed, for the log; nil when it worked.
    private(set) var lastError: String?
    private let scoped: Bool
    private let now: () -> Int64
    private let newID: () -> String
    /// Set by `load` when shelf.json holds something reading it would lose: the first write keeps a copy of the old file.
    private var backupFirst = false

    init(support: URL, scoped: Bool = ShelfStore.isAppStoreBuild,
         now: @escaping () -> Int64 = { Int64(Date().timeIntervalSince1970 * 1000) },
         newID: @escaping () -> String = { UUID().uuidString.replacingOccurrences(of: "-", with: "").lowercased() }) {
        self.support = support
        self.scoped = scoped
        self.now = now
        self.newID = newID
    }

    var file: URL { support.appendingPathComponent("shelf.json") }
    var copiesRoot: URL { support.appendingPathComponent("shelf") }
    func folder(for id: String) -> URL { copiesRoot.appendingPathComponent(id, isDirectory: true) }
    func copyURL(_ item: ShelfItem) -> URL { folder(for: item.id).appendingPathComponent(item.name) }

    // MARK: Reading and writing the list

    func load() {
        guard let data = try? Data(contentsOf: file) else { items = []; backupFirst = false; return }
        let bytes = [UInt8](data)
        items = ShelfRules.read(bytes)
        backupFirst = !bytes.isEmpty && !ShelfRules.isLossless(bytes)
    }

    @discardableResult
    private func save() -> Bool {
        let fm = FileManager.default
        do {
            try fm.createDirectory(at: support, withIntermediateDirectories: true)
            if backupFirst, fm.fileExists(atPath: file.path) {
                // An unreadable (or partly unreadable) shelf.json is never overwritten before it is kept.
                var bad = support.appendingPathComponent("shelf.json.bad-\(now())")
                var n = 1
                while fm.fileExists(atPath: bad.path) { bad = support.appendingPathComponent("shelf.json.bad-\(now())-\(n)"); n += 1 }
                try fm.copyItem(at: file, to: bad)
            }
            backupFirst = false
            try ShelfRules.encode(items).write(to: file, options: .atomic)
            lastError = nil
            return true
        } catch {
            lastError = "\(error)"
            return false
        }
    }

    // MARK: Adding

    private func bookmarkOptions() -> URL.BookmarkCreationOptions { scoped ? [.withSecurityScope] : [] }
    private func resolveOptions() -> URL.BookmarkResolutionOptions { scoped ? [.withSecurityScope, .withoutUI] : [.withoutUI] }

    /// The item for one original, or nil when it cannot be read or bookmarked.
    private func linkItem(_ url: URL) -> ShelfItem? {
        let values = try? url.resourceValues(forKeys: [.isDirectoryKey, .fileSizeKey])
        guard let bookmark = try? url.bookmarkData(options: bookmarkOptions(), includingResourceValuesForKeys: nil, relativeTo: nil) else { return nil }
        return ShelfItem(id: newID(), name: url.lastPathComponent, size: Int64(values?.fileSize ?? 0), folder: values?.isDirectory == true, copy: false, link: bookmark.base64EncodedString(), addedAt: now())
    }

    /// The item for a file with no original, copied into its own folder; nil when the copy cannot be made.
    private func copyItem(_ url: URL) -> ShelfItem? {
        let id = newID(), name = url.lastPathComponent
        let item = ShelfItem(id: id, name: name, size: Int64((try? url.resourceValues(forKeys: [.fileSizeKey]).fileSize) ?? 0), folder: false, copy: true, link: nil, addedAt: now())
        let fm = FileManager.default
        do {
            try fm.createDirectory(at: folder(for: id), withIntermediateDirectories: true)
            try fm.copyItem(at: url, to: copyURL(item))
            return item
        } catch {
            try? fm.removeItem(at: folder(for: id))
            return nil
        }
    }

    /// The paths of the originals the shelf already holds, so that the same file dropped twice is a duplicate even though two bookmarks of it are not the same bytes.
    private func heldPaths() -> Set<String> {
        Set(items.compactMap { $0.copy ? nil : bookmarkTarget($0)?.url.standardizedFileURL.path })
    }

    /// One word for each dropped file, in order (docs/SHELF-CONTRACT.md: added, duplicate, full or invalid). Writes shelf.json once.
    @discardableResult
    func add(_ incoming: [ShelfIncoming]) -> [ShelfAddResult] {
        var held = heldPaths()
        var candidates: [ShelfItem?] = []
        var precheck: [ShelfAddResult?] = []
        for one in incoming {
            switch one {
            case .file(let url):
                let path = url.standardizedFileURL.path
                if held.contains(path) { candidates.append(nil); precheck.append(.duplicate); continue }
                held.insert(path)
                let item = linkItem(url)
                candidates.append(item)
                precheck.append(item == nil ? .invalid : nil)
            case .temporary(let url):
                let item = copyItem(url)
                candidates.append(item)
                precheck.append(item == nil ? .invalid : nil)
            }
        }
        let real = candidates.compactMap { $0 }
        let r = ShelfRules.add(items, real)
        var next = r.results.makeIterator()
        var results: [ShelfAddResult] = []
        for (k, c) in candidates.enumerated() {
            if let p = precheck[k] { results.append(p); continue }
            let word = next.next() ?? .invalid
            results.append(word)
            // A copy that was not added must not stay on disk.
            if word != .added, let c, c.copy { try? FileManager.default.removeItem(at: folder(for: c.id)) }
        }
        if r.results.contains(.added) {
            items = r.items
            save()
        }
        return results
    }

    // MARK: Using an item

    /// An item's bookmark resolved: its file, and whether macOS says the bookmark is stale. Nil when it does not resolve. The file may still be missing; ask `checkMissing`.
    private func bookmarkTarget(_ item: ShelfItem) -> (url: URL, stale: Bool)? {
        guard let text = item.link, let data = Data(base64Encoded: text) else { return nil }
        var stale = false
        guard let url = try? URL(resolvingBookmarkData: data, options: resolveOptions(), relativeTo: nil, bookmarkDataIsStale: &stale) else { return nil }
        return (url, stale)
    }

    /// Opens an item for use (a drag, Ask, Send, Show in Finder): its file with the security scope started. Nil when the file is gone. A stale bookmark is renewed.
    func open(_ item: ShelfItem) -> ShelfAccess? {
        if item.copy {
            let url = copyURL(item)
            return FileManager.default.fileExists(atPath: url.path) ? ShelfAccess(url: url, scoped: false) : nil
        }
        guard let target = bookmarkTarget(item) else { return nil }
        let started = target.url.startAccessingSecurityScopedResource()
        guard FileManager.default.fileExists(atPath: target.url.path) else {
            if started { target.url.stopAccessingSecurityScopedResource() }
            return nil
        }
        if target.stale, let fresh = try? target.url.bookmarkData(options: bookmarkOptions(), includingResourceValuesForKeys: nil, relativeTo: nil),
           let at = items.firstIndex(where: { $0.id == item.id }) {
            items[at].link = fresh.base64EncodedString()
            save()
        }
        return ShelfAccess(url: target.url, scoped: started)
    }

    /// The ids of the items whose file is gone. Run when the shelf opens, never in the background.
    func checkMissing() -> Set<String> {
        var missing = Set<String>()
        for item in items {
            if let a = open(item) { a.end() } else { missing.insert(item.id) }
        }
        return missing
    }

    // MARK: Removing

    /// Removes an item. Its copy, if it has one, is deleted; an original is never touched.
    func remove(id: String) {
        guard let at = items.firstIndex(where: { $0.id == id }) else { return }
        let item = items.remove(at: at)
        if item.copy { try? FileManager.default.removeItem(at: folder(for: item.id)) }
        save()
    }

    func clear() {
        for item in items where item.copy { try? FileManager.default.removeItem(at: folder(for: item.id)) }
        items = []
        save()
    }
}
```

```swift
import Foundation

// The drop halves (sub-project G1): while files are dragged over the open notch it splits at its centre line into Ask (the left half, today's drop) and Shelf (the right half). Foundation
// only. Which half the pointer is in is `ShelfRules.zoneAt` (the shared contract); what each half accepts is here.

/// The half of the open island the pointer is over. Ask is the canvas that ships; Shelf is the layer added on top of it.
enum DropHalf: String, Sendable { case ask, shelf }

/// What a drag carries that NotchMeow can use.
enum DragKind: Hashable, Sendable {
    /// File URLs: what the drop accepts today.
    case fileURL
    /// Promised files (Mail, Photos, a screenshot thumbnail): the sender writes the file when asked.
    case promisedFile
    /// An image with no file behind it (dragged out of a browser).
    case image
}

enum ShelfDrop {
    /// The open island's width, which the halves are measured against (`IslandConst.expandedWidth`): a drag over the notch always opens the island to this width.
    static let islandWidth: Double = 640

    /// The half for a pointer `x` points from the island's left edge. Outside the island there is no half in the contract; the drop view covers the whole panel and has always taken a drop
    /// anywhere on it as the Ask drop, so outside is Ask.
    static func half(x: Double, width: Double = islandWidth) -> DropHalf {
        ShelfRules.zoneAt(x: x, width: width) == .shelf ? .shelf : .ask
    }

    /// Whether the drop is accepted over `half`. File URLs are accepted over both halves, as they are today. Promised files and browser images only over Shelf; over Ask they are refused,
    /// exactly as they are today (the drop view never saw them).
    static func accepts(_ kinds: Set<DragKind>, over half: DropHalf) -> Bool {
        if kinds.contains(.fileURL) { return true }
        return half == .shelf && (kinds.contains(.promisedFile) || kinds.contains(.image))
    }

    /// Whether a drag opens the island at all: the ones that can be dropped somewhere.
    static func opensIsland(_ kinds: Set<DragKind>) -> Bool {
        !kinds.isEmpty
    }
}
```

```swift
// Run it through scripts/render-shelf.sh:  bash scripts/render-shelf.sh --drop --out DIR   |   --ask-check

/// The same helper the app has in IslandRootView.swift (that file needs the whole app; the sheets do not).
extension Color {
    init(hex: String) {
        let h = hex.trimmingCharacters(in: CharacterSet(charactersIn: "#"))
        let val = UInt64(h, radix: 16) ?? 0
        self.init(red: Double((val >> 16) & 0xFF) / 255, green: Double((val >> 8) & 0xFF) / 255, blue: Double(val & 0xFF) / 255)
    }
}

enum Shot {
    static let scale: CGFloat = 2

    @MainActor static func image<V: View>(_ view: V, opaque: Bool = true) -> CGImage? {
        let r = ImageRenderer(content: view)
        r.scale = scale
        r.isOpaque = opaque
        return r.cgImage
    }

    @MainActor static func save<V: View>(_ view: V, to url: URL) {
        guard let cg = image(view), let png = NSBitmapImageRep(cgImage: cg).representation(using: .png, properties: [:]) else {
            FileHandle.standardError.write(Data("could not draw \(url.lastPathComponent)\n".utf8)); exit(1)
        }
        try! png.write(to: url)
        print("wrote \(url.path)")
    }

    /// RGBA bytes of an image, premultiplied, row by row from the top.
    static func pixels(_ cg: CGImage) -> (w: Int, h: Int, bytes: [UInt8]) {
        let w = cg.width, h = cg.height
        var bytes = [UInt8](repeating: 0, count: w * h * 4)
        bytes.withUnsafeMutableBytes { p in
            let c = CGContext(data: p.baseAddress, width: w, height: h, bitsPerComponent: 8, bytesPerRow: w * 4, space: CGColorSpace(name: CGColorSpace.sRGB)!, bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)!
            c.draw(cg, in: CGRect(x: 0, y: 0, width: w, height: h))
        }
        return (w, h, bytes)
    }
}

struct RenderShelf {
    /// The Ask half is the canvas as it ships: the layer draws nothing left of the centre line, in either state. Fails (exit 1) on a single pixel with any alpha at x < 320.
    @MainActor static func askCheck() {
        var bad = 0
        for half in [DropHalf.ask, DropHalf.shelf] {
            guard let cg = Shot.image(ShelfDropLayer(half: half), opaque: false) else { print("✗ could not draw the layer"); exit(1) }
            let p = Shot.pixels(cg)
            let split = Int(320 * Shot.scale)
            var left = 0, right = 0
            for y in 0..<p.h { for x in 0..<p.w where p.bytes[(y * p.w + x) * 4 + 3] != 0 { if x < split { left += 1 } else { right += 1 } } }
            if left == 0 && right > 0 { print("✓ over \(half.rawValue): the layer draws \(right) pixels right of the centre line and none left of it (\(p.w) x \(p.h))") } else { print("✗ over \(half.rawValue): \(left) pixels left of the centre line, \(right) right of it"); bad += 1 }
        }
        if bad > 0 { exit(1) }
    }

    @MainActor static func main() {
        var out = ".", modes: [String] = []
        var it = CommandLine.arguments.dropFirst().makeIterator()
        while let k = it.next() {
            switch k {
            case "--out": out = it.next() ?? out
            case "--drop", "--ask-check": modes.append(k)
            default: FileHandle.standardError.write(Data("unknown argument \(k)\n".utf8)); exit(2)
            }

        if modes.isEmpty { FileHandle.standardError.write(Data("say what to draw: --drop, --ask-check\n".utf8)); exit(2) }
        _ = NSApplication.shared
        let dir = URL(fileURLWithPath: out, isDirectory: true)
        try? FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        for m in modes {
            switch m {
            case "--ask-check": askCheck()
            case "--drop": Shot.save(DropSheet(), to: dir.appendingPathComponent("shelf-drop.png"))
            default: break
            }
        }
    }
}
```

```swift
import Combine
import Foundation

// What the shelf view shows and the actions on it (sub-project G1): the store's items, which of them are selected, which have gone missing, and the note after a drop. Foundation and Combine
// only, so the render script and the tests can build one on a store in a temp folder; the app's own is `ShelfModel.shared` (ShelfModel+App.swift).

@MainActor
final class ShelfModel: ObservableObject {
    @Published private(set) var items: [ShelfItem] = []
    /// Items whose file is gone. Asked when the shelf opens (`refresh`), never in the background.
    @Published private(set) var missing: Set<String> = []
    @Published private(set) var selection: Set<String> = []
    /// What to tell the user after a drop that did not add everything; cleared by the next change.
    @Published private(set) var note: String?
    let store: ShelfStore

    init(store: ShelfStore) {
        self.store = store
        store.load()
        items = store.items
    }

    var count: Int { items.count }
    /// The selected items, in the shelf's order.
    var selected: [ShelfItem] { items.filter { selection.contains($0.id) } }

    private func sync() {
        items = store.items
        let ids = Set(items.map(\.id))
        selection.formIntersection(ids)
        missing.formIntersection(ids)
    }

    /// Files dropped on the Shelf half. Returns one word for each, and sets the note.
    @discardableResult
    func add(_ incoming: [ShelfIncoming]) -> [ShelfAddResult] {
        let results = store.add(incoming)
        sync()
        note = ShelfDrop.note(results)
        return results
    }

    /// The shelf opened: ask which files are still there.
    func refresh() {
        missing = store.checkMissing()
    }

    func toggle(_ id: String) {
        guard items.contains(where: { $0.id == id }) else { return }
        if selection.contains(id) { selection.remove(id) } else { selection.insert(id) }
        note = nil
    }

    func remove(_ ids: Set<String>) {
        for id in ids { store.remove(id: id) }
        sync()
        note = nil
    }

    func clear() {
        store.clear()
        sync()
        selection = []
        missing = []
        note = nil
    }

    func dismissNote() { note = nil }

    func open(_ item: ShelfItem) -> ShelfAccess? { store.open(item) }
}
```

```swift
import AppKit

// Reading what a drop on the Shelf half carries (sub-project G1). File URLs become links. A promised file (Mail, Photos, a screenshot thumbnail) is asked for into a fresh temp folder, and
// an image dragged out of a browser is written there as a PNG; both become copies on the shelf, and the caller removes the temp folder once the store has taken what it keeps. Only the
// drag's own file and image data are read: no URL on the pasteboard is ever fetched.

@MainActor
enum ShelfDropReader {
    /// The types the drop view registers for besides file URLs: what promised files are announced with, and raw image data.
    static var extraTypes: [NSPasteboard.PasteboardType] {
        NSFilePromiseReceiver.readableDraggedTypes.map { NSPasteboard.PasteboardType($0) } + [.tiff, .png]
    }

    /// What the pasteboard carries that the shelf can use.
    static func kinds(of pb: NSPasteboard) -> Set<DragKind> {
        var k: Set<DragKind> = []
        if pb.canReadObject(forClasses: [NSURL.self], options: [.urlReadingFileURLsOnly: true]) { k.insert(.fileURL) }
        if pb.canReadObject(forClasses: [NSFilePromiseReceiver.self], options: nil) { k.insert(.promisedFile) }
        if pb.types?.contains(where: { $0 == .png || $0 == .tiff }) == true { k.insert(.image) }
        return k
    }

    /// Collects the promised files as they arrive and finishes once the last one has.
    private final class Collector {
        var items: [ShelfIncoming] = []
        private var pending = 0
        private var armed = false
        private var finished = false
        private let folder: URL
        private let done: @MainActor ([ShelfIncoming], URL?) -> Void

        init(folder: URL, done: @escaping @MainActor ([ShelfIncoming], URL?) -> Void) { self.folder = folder; self.done = done }

        func expect() { pending += 1 }

        @MainActor func arrived(_ url: URL?) {
            pending -= 1
            if let url { items.append(.temporary(url)) }
            finishIfReady()
        }

        /// Everything is asked for: finish now if nothing is pending.
        @MainActor func arm() { armed = true; finishIfReady() }

        @MainActor private func finishIfReady() {
            guard armed, pending <= 0, !finished else { return }
            finished = true
            done(items, folder)
        }
    }

    /// `done` gets the items and the temp folder holding the files received or written for this drop (nil for plain file URLs; the caller removes it when it is finished with the files).
    static func read(_ pb: NSPasteboard, kinds: Set<DragKind>, done: @escaping @MainActor ([ShelfIncoming], URL?) -> Void) {
        if kinds.contains(.fileURL) {
            let urls = (pb.readObjects(forClasses: [NSURL.self], options: [.urlReadingFileURLsOnly: true]) as? [URL]) ?? []
            done(urls.map { .file($0) }, nil)
            return
        }
        let folder = FileManager.default.temporaryDirectory.appendingPathComponent("NotchMeow-drop-\(UUID().uuidString)", isDirectory: true)
        try? FileManager.default.createDirectory(at: folder, withIntermediateDirectories: true)
        let box = Collector(folder: folder, done: done)
        var promised = 0
        if kinds.contains(.promisedFile) {
            for receiver in (pb.readObjects(forClasses: [NSFilePromiseReceiver.self], options: nil) as? [NSFilePromiseReceiver]) ?? [] {
                promised += 1
                box.expect()
                receiver.receivePromisedFiles(atDestination: folder, options: [:], operationQueue: .main) { url, error in
                    Task { @MainActor in box.arrived(error == nil ? url : nil) }
                }
            }
        }
        if promised == 0, kinds.contains(.image), let png = imagePNG(pb) {
            let url = folder.appendingPathComponent("Image.png")
            if (try? png.write(to: url)) != nil { box.items.append(.temporary(url)) }
        }
        box.arm()
    }

    /// The image on the pasteboard as PNG bytes: the PNG itself, or the TIFF converted.
    static func imagePNG(_ pb: NSPasteboard) -> Data? {
        if let png = pb.data(forType: .png) { return png }
        guard let tiff = pb.data(forType: .tiff), let rep = NSBitmapImageRep(data: tiff) else { return nil }
        return rep.representation(using: .png, properties: [:])
    }
}
```

```swift
import AppKit
import SwiftUI

// Dragging files out of the shelf (sub-project G1): a tile is also an AppKit view that turns a press that moves into a drag session, so the files can be dropped anywhere (Finder, Mail, a chat,
// a terminal). The session's source is `ShelfDragSource`: while it runs the island stays open and the panel keeps taking the mouse (`AppState.shelfHoldsIsland`, set by the hooks the view is
// given), and the drop view refuses a drag that started inside the app, so a file dragged out and back in is not added twice. Each file is opened (`ShelfStore.open`) for the length of the
// session, so a security-scoped original stays readable until the drop has finished.

/// What the app does when a drag out begins and ends (the render script and the tests give none).
struct ShelfDragHooks {
    var began: @MainActor () -> Void
    var ended: @MainActor () -> Void
    @MainActor static let none = ShelfDragHooks(began: {}, ended: {})
}

/// The drag session's source. It lets the files be copied by anything outside the app and refuses a drop inside it.
@MainActor
final class ShelfDragSource: NSObject, NSDraggingSource {
    private var accesses: [ShelfAccess]
    private let onEnd: @MainActor () -> Void

    init(accesses: [ShelfAccess], onEnd: @escaping @MainActor () -> Void) {
        self.accesses = accesses
        self.onEnd = onEnd
    }

    func draggingSession(_ session: NSDraggingSession, sourceOperationMaskFor context: NSDraggingContext) -> NSDragOperation {
        context == .outsideApplication ? .copy : []
    }

    func draggingSession(_ session: NSDraggingSession, endedAt screenPoint: NSPoint, operation: NSDragOperation) {
        for a in accesses { a.end() }
        accesses = []
        onEnd()
    }

/// A tile's mouse: a click selects it, a press that moves 4 pt drags the item out, or the whole selection when the tile is part of it.
@MainActor
final class ShelfTileNSView: NSView {
    var model: ShelfModel?
    var item: ShelfItem?
    var hooks = ShelfDragHooks.none
    private var pressed: NSEvent?
    private var dragging = false
    private var source: ShelfDragSource?

    /// The island is a panel that never activates: the first press must count.
    override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }

    override func mouseDown(with event: NSEvent) {
        pressed = event
        dragging = false
    }

    override func mouseDragged(with event: NSEvent) {
        guard !dragging, let start = pressed, hypot(event.locationInWindow.x - start.locationInWindow.x, event.locationInWindow.y - start.locationInWindow.y) > 4 else { return }
        dragging = true
        beginDrag(with: event)
    }

    override func mouseUp(with event: NSEvent) {
        if !dragging, let id = item?.id { model?.toggle(id) }
        pressed = nil
        dragging = false
    }

    private func beginDrag(with event: NSEvent) {
        guard let model, let item else { return }
        let chosen = model.selection.contains(item.id) ? model.selected : [item]
        let accesses = chosen.compactMap { model.open($0) }   // a missing file is skipped
        guard !accesses.isEmpty else { return }
        let src = ShelfDragSource(accesses: accesses) { [weak self] in
            self?.source = nil
            self?.hooks.ended()
        }
        source = src
        let p = convert(event.locationInWindow, from: nil)
        let dragItems = accesses.enumerated().map { i, a -> NSDraggingItem in
            let di = NSDraggingItem(pasteboardWriter: a.url as NSURL)
            let icon = NSWorkspace.shared.icon(forFile: a.url.path)
            icon.size = NSSize(width: 40, height: 40)
            di.setDraggingFrame(NSRect(x: p.x - 20 + CGFloat(i) * 6, y: p.y - 20 - CGFloat(i) * 6, width: 40, height: 40), contents: icon)
            return di
        }
        hooks.began()
        let session = beginDraggingSession(with: dragItems, event: event, source: src)
        session.animatesToStartingPositionsOnCancelOrFail = true
    }
}
```

```swift
// What the shelf's buttons do (sub-project G1). Each opens the item first (`ShelfStore.open`: a security-scoped original is readable only while it is open).

@MainActor
enum ShelfActions {
    /// The file Ask is reading stays open until the next Ask: the chat reads and copies it after this returns.
    private static var held: ShelfAccess?

    /// Ask: hands the file to the chat the way a drop on the Ask half does. The upload sequence starts and the island shows its canvas, then `FileDropHandler.handle` runs the drop as it always has: the desktop
    /// cat catches the file if it is out, the cat catches it at the notch, the conversation resets and the file is the chat's context.
    static func ask(_ item: ShelfItem, model: ShelfModel, state: AppState = .shared) {
        guard ShelfActionRules.canAsk([item], missing: model.missing), let access = model.open(item) else { return }
        held?.end()
        held = access
        state.fileDragOver = true
        UploadSequenceEngine.shared.enterZone(x: 320, y: 110)
        NotificationCenter.default.post(name: .hookExpand, object: IslandView.upload)
        Task { @MainActor in await FileDropHandler.handle(urls: [access.url], state: state) }
    }

    /// Show in Finder (the system's file viewer, with the items selected). Never touches the files.
    static func showInFinder(_ items: [ShelfItem], model: ShelfModel) {
        let accesses = items.compactMap { model.open($0) }
        guard !accesses.isEmpty else { return }
        NSWorkspace.shared.activateFileViewerSelecting(accesses.map(\.url))
        for a in accesses { a.end() }
    }
}
```

```swift
import AppKit

// Send (sub-project G1): the standard share picker (`NSSharingServicePicker`) and a one-click AirDrop button (`NSSharingService(named: .sendViaAirDrop)`). Sending always starts with a click,
// and the system's sheet keeps the recipients private from NotchMeow: the log says only that a send started, never names or recipients. While the picker or the AirDrop window is up the island
// stays open (`AppState.sharePickerSince`, a clock reading with a limit: `ShelfHold`). Each item is opened (`ShelfStore.open`) until the share is over, so a security-scoped original stays
// readable. The island is a panel that never activates, so it takes the key for the picker the way the chat does for its text field.

@MainActor
final class ShelfSend: NSObject, @MainActor NSSharingServicePickerDelegate, @MainActor NSSharingServiceDelegate {
    static let shared = ShelfSend()

    private var accesses: [ShelfAccess] = []
    private var state: AppState { AppState.shared }

    /// Opens the items for the share. Nil when any of them has gone missing (the buttons are off for that, this is the second line).
    private func begin(_ items: [ShelfItem], model: ShelfModel) -> [URL]? {
        finish()
        let opened = items.compactMap { model.open($0) }
        guard opened.count == items.count, !opened.isEmpty else {
            for a in opened { a.end() }
            return nil
        }
        accesses = opened
        state.sharePickerSince = ProcessInfo.processInfo.systemUptime
        appendAppLog("shelf.log", "a send started")
        return opened.map(\.url)
    }

    /// The share is over (a service ran, failed, or the picker closed with none chosen): the files are closed and the island may fold again.
    func finish() {
        for a in accesses { a.end() }
        accesses = []
        state.sharePickerSince = nil
    }

    /// The share picker, below the island. The island's panel takes the key first.
    func showPicker(_ items: [ShelfItem], model: ShelfModel) {
        guard ShelfActionRules.canSend(items, missing: model.missing), let urls = begin(items, model: model) else { return }
        guard let panel = NSApp.windows.first(where: { $0 is IslandPanel }), let content = panel.contentView else { finish(); return }
        panel.makeKey()
        let picker = NSSharingServicePicker(items: urls)
        picker.delegate = self
        let anchor = NSRect(x: content.bounds.midX - 1, y: content.bounds.height - 176, width: 2, height: 2)
        picker.show(relativeTo: anchor, of: content, preferredEdge: .minY)
    }

    /// AirDrop in one click. When this Mac cannot AirDrop these items, the picker is the way to send them, and says nothing here.
    func airDrop(_ items: [ShelfItem], model: ShelfModel) {
        guard ShelfActionRules.canSend(items, missing: model.missing), let urls = begin(items, model: model) else { return }
        guard let service = NSSharingService(named: .sendViaAirDrop), service.canPerform(withItems: urls) else { finish(); return }
        service.delegate = self
        service.perform(withItems: urls)
    }

    // MARK: NSSharingServicePickerDelegate

    func sharingServicePicker(_ picker: NSSharingServicePicker, delegateFor service: NSSharingService) -> NSSharingServiceDelegate? { self }

    /// `service` is nil when the picker closed without a choice.
    func sharingServicePicker(_ picker: NSSharingServicePicker, didChoose service: NSSharingService?) {
        if service == nil { finish() }
    }

    // MARK: NSSharingServiceDelegate

    func sharingService(_ sharingService: NSSharingService, didShareItems items: [Any]) { finish() }
    func sharingService(_ sharingService: NSSharingService, didFailToShareItems items: [Any], error: Error) { finish() }
}
```

```swift
import CoreGraphics
import Foundation

// The shelf's badge on the compact island (sub-project G1): a small count at the right end of the right wing, one more cell beside the grid of agent cats. Pure rules, Foundation and
// CoreGraphics only. It shows only while the island is already compact and the shelf is not empty: it never keeps an island visible and never wakes a hidden one. It fades with the wing
// (`IslandWing`, unchanged) because it is drawn with the grid; it does not touch Two cats or the kitten layouts, which do not use the wing's right end.

enum ShelfBadge {
    /// The badge's diameter (pt) in the 32 pt strip, and how far its centre is from the island's right edge. The grid's cells are 12 pt wide, centred 40 pt in, so its right edge is 26 pt in;
    /// the badge's left edge is 21 pt in, 5 pt clear of the last cell.
    static let diameter: CGFloat = 14
    static let inset: CGFloat = 14
    /// How far beyond the badge a click still counts as on it.
    static let hitSlop: CGFloat = 4

    /// Whether the badge is on screen: only in the compact island, with something on the shelf, and not while the greeting's tail still draws the session cats in the grid's place.
    static func isShown(compact: Bool, count: Int, greetingTail: Bool) -> Bool { compact && !greetingTail && count > 0 }

    /// The strip shrinks the grid below 32 pt (`IslandRestingLayout.miniGridScale`); the badge shrinks with it.
    static func scale(height: CGFloat) -> CGFloat { min(1, max(0, height - 4) / 28) }

    /// The badge's centre in the island's own coordinates (y down, the island's top left the origin).
    static func center(islandWidth: CGFloat, height: CGFloat) -> CGPoint { CGPoint(x: islandWidth - inset, y: height / 2) }

    /// The rectangle a click counts in, in the same coordinates as `island` (the island's frame in the panel, whichever way y runs).
    static func hitRect(island: CGRect) -> CGRect {
        let k = scale(height: island.height)
        let r = diameter / 2 * k + hitSlop
        return CGRect(x: island.maxX - inset - r, y: island.midY - r, width: 2 * r, height: 2 * r)
    }
}
```

```swift
/// The Debug-only shelf panel's model (sub-project G1): a shelf on a store in a temp folder, with buttons that fill it with real files, so the shelf view, the full-shelf note, a missing file and
/// the drop halves can be looked at and tried without touching the app's own shelf. Compiled in Debug builds only: `scripts/check-app-binary.sh` proves it is not in Release or App Store builds

@MainActor
final class ShelfDevModel: ObservableObject {
    static let marker = "NM_SHELF_DEV_PANEL"

    let shelf: ShelfModel
    let root: URL
    /// The half the drop layer shows as lit.
    @Published var half: DropHalf = .shelf

    @Published private(set) var log: [String] = []

    init(root: URL = FileManager.default.temporaryDirectory.appendingPathComponent("NotchMeow-shelf-dev-\(UUID().uuidString)", isDirectory: true)) {
        self.root = root
        try? FileManager.default.createDirectory(at: root.appendingPathComponent("originals"), withIntermediateDirectories: true)
        shelf = ShelfModel(store: ShelfStore(support: root.appendingPathComponent("support"), scoped: false))
    }

    func say(_ line: String) { log.append(line); if log.count > 8 { log.removeFirst(log.count - 8) } }

    /// A real file of `bytes` zeros in a folder of its own, so the same name can be made twice.
    private func make(_ name: String, bytes: Int) -> URL {
        counter += 1
        let dir = root.appendingPathComponent("originals/\(counter)", isDirectory: true)
        try? FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        let url = dir.appendingPathComponent(name)
        try? Data(count: bytes).write(to: url)
        return url
    }

    func addSamples() {
        let r = shelf.add([.file(make("Quarterly report.pdf", bytes: 2_400_000)), .file(make("notes.txt", bytes: 1_200)), .file(make("demo.mov", bytes: 48_000_000))])
        say("dropped 3 files: \(r.map(\.rawValue).joined(separator: ", "))")
    }

    func addImageCopy() {
        let r = shelf.add([.temporary(make("Image.png", bytes: 48_000))])
        say("dropped an image with no original (a copy): \(r.map(\.rawValue).joined(separator: ", "))")
    }

    /// Fills the shelf to its 30.
    func fill() {
        let room = max(0, ShelfRules.max - shelf.count)
        let r = shelf.add((0..<room).map { .file(make("file-\(counter + $0).txt", bytes: 1_000)) })
        say("filled the shelf: \(r.count) added")
    }

    /// Two more files on a full shelf: both are refused and nothing old is removed.
    func dropTwoMore() {
        let r = shelf.add([.file(make("extra-a.txt", bytes: 10)), .file(make("extra-b.txt", bytes: 10))])
        say("dropped 2 more: \(r.map(\.rawValue).joined(separator: ", "))")
    }

    /// Deletes the original of the newest linked item, so it shows as missing.
    func deleteAnOriginal() {
        guard let item = shelf.items.first(where: { !$0.copy }), let access = shelf.open(item) else { say("no link to delete"); return }
        let url = access.url
        access.end()
        try? FileManager.default.removeItem(at: url)
        shelf.refresh()

    }

        shelf.clear()
```
