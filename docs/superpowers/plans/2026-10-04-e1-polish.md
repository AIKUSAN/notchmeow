# E1 Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking. This plan bundles follow-ups from the E1 macOS and Windows/Linux sessions. Each unit names the behaviour, the files and the tests. Implementers write the code test-first, following the surrounding code: the units are small fixes inside code that already exists, so the plan doesn't repeat that code.

**Goal:** Close the follow-ups both E1 sessions left after their final reviews:
- Windows/Linux catches up with the Mac's late fixes;
- discovery and error-message edge cases;
- robustness in settings and drops;
- stale docs and the CI gaps.

**Architecture:** No new architecture. Each unit changes existing E1 code and adds a regression test next to it:
- Windows/Linux: `windows/src-tauri/src/ai/*` and `windows/src/**`;
- macOS: `NotchBuddy/Sources/App/AI/**`;
- plus the docs and the workflows.

**Tech Stack:** Rust (Tauri 2), TypeScript, Swift 6, GitHub Actions YAML.

**Specs:** `docs/superpowers/specs/2026-10-03-local-models-design.md`. The two E1 plans are `docs/superpowers/plans/2026-10-03-e1-mac-local-models.md` and `2026-10-03-e1-tauri-local-models.md`. The shared contract is `tests/fixtures/ai/`.

**Base:** branch `e1/polish` in a git worktree, from `notchmeow/rebrand` at the post-merge verification commit (`683dbfb` or the Windows-check fix on top of it).

## Global Constraints
- **The contract is read-only.** If a unit seems to need a contract change, stop and report.
- **The Mac stays dependency-free.** Secrets stay in the Keychain or Credential Manager only. No telemetry. Logs carry no prompts, file contents or keys.
- **Never restyle shipping views.** Never rename pill IDs or contract strings.
- **Copy rule:** user-visible wording follows the spec's error-copy table. New wording appears only where this plan gives it.
- **Rust:** run through `windows/scripts/cargo-linux.sh` (Docker). For the Windows target, `cargo check --target x86_64-pc-windows-gnu` runs inside the same container. Never install toolchains on the host.
- **Your log:** `~/Library/Logs/NotchMeow/nm.log` must not grow. Test scripts export `NM_LOG_DIR`.
- **Commits:** local only, never pushed. Trailers name the model that did the work.

## Review Focus
1. **A refusal with an empty body** must never fall back to a local model, on either platform.
2. **A local reasoning model that thinks for longer than the first-token deadline** must not be cut off.
3. **Being offline** must never show "key rejected".
4. **A settings file with a hand-edit error** must be kept as a backup, never silently wiped.
5. **A server the user added on a slow network** must not flip to "off" because of the 0.3 s probe meant for localhost.

### Unit 1: Windows/Linux catches up with the Mac's late fixes (`nm-implementer`)
**Files:** `windows/src-tauri/src/ai/session.rs`, `router.rs`, `openai_compat.rs`, `sse.rs`, `discovery.rs` and `windows/src-tauri/src/settings.rs`, with tests in the same modules.

For each item, mirror what the Mac does. Read the Mac code named here first.
- [ ] **1a. Empty refusals never fall back** (Mac ruling R14: `ChatRunner.swift`, `ModelRouter.swift`). A refusal with an empty or missing message is still a refusal: no local retry, the refusal note shown. Test: an Anthropic `stop_reason: "refusal"` with no text, and an OpenAI `response.refusal` with an empty delta, each give `refusal` with no fallback.
- [ ] **1b. Reasoning deltas count as first output on local servers** (Mac R15: `OpenAICompatibleProvider.swift`, `SSEParsers.swift`). For OpenAI-compatible streams, a `reasoning_content` or `reasoning` delta, or text inside `<think>`, stops the first-token deadline. Test: a stream that sends only reasoning for 61 s (simulated clock) and then text completes, and isn't timed out.
- [ ] **1c. The migration keeps a pre-E1 local or Google choice** (Mac R16: `ModelRouter`/settings migration). An old setting that picked Ollama, LM Studio or Google without a stored model keeps that provider with its old default model. It doesn't become cloud Auto. Test: migrate an old `settings.json` fixture for each case.
- [ ] **1d. Auto rescans once for a local server** after a temporary cloud failure, when none was known (Mac R18: `ChatRunner.swift`). One 0.3 s scan, and only once per message. Test: no local server known, cloud fails with `overloaded`, and the scan finds a fake server, so the fallback answers.
- [ ] **1e. Cloud reasoning isn't cut off by the 120 s silence limit** (Tauri M-3). For OpenAI Responses, reasoning or summary events and `response.in_progress` reset the silence clock. Keep the 120 s limit otherwise. Test: events every 100 s for 5 min, and the turn completes.
- [ ] **1f. Read local context sizes** (Tauri M-4).
  - Ollama: `POST /api/show` `model_info.*.context_length`, or `parameters` `num_ctx` when set.
  - LM Studio: `max_context_length` from `/api/v0/models`.
  - When a value is present, use it as `contextTokens` instead of 4,096. Otherwise 4,096 stays.
  - Mirror whatever the Mac's `Discovery.swift` does. If the Mac doesn't read context sizes either, do the same on both platforms in this unit, and add the Mac change and its test.
  - Test: fake server personas report context sizes, and the budget uses them.
