# D1-site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give NotchMeow its site, for GitHub Pages from `docs/`: a home page whose live Shrimpy and Momo are the Windows app's own cats, a row of the 16 coats, pictures drawn by the Mac render scripts, a testers page, and the two scripts that keep it honest, `scripts/render-site.sh` (redraws the pictures at 2x) and `scripts/check-site.sh` (fails on a stale bundle or on any request to another host). The owner looks at the page at a checkpoint before the pages are committed.

**Architecture:** One new entry, `windows/src/site/main.ts`, draws two `BotEngine`s from `windows/src/cat/` (the engine and renderer the app and `npm run check:cat` already use) into two canvases and a row of 16 coat stills, and is bundled by the Vite already in `windows/`, with its own config (`windows/vite.site.config.ts`), into `docs/assets/cats.js` and `cats.css` (the generated theme tokens come in through one CSS import). The engine needs nothing from the island but a canvas, a frame time and the pointer, so the entry is its whole stand-in; the app's sound module is swapped for a silent one, so the bundle carries no audio and no network code. What the cats decide (when to draw, which cat a coat goes to) is plain data in `windows/src/site/rules.ts`, tested in Node. The pages are plain HTML and one CSS file that reads the theme tokens; the pictures are PNGs from the render scripts, with one new script (`render-approval-card`) for the approval card. `check-site.sh` rebuilds the bundle into a temporary folder and compares, and greps the pages for outside requests, cookies, missing alt text and the wrong names; `test-check-site.sh` proves each rule bites. The Windows tests workflow runs both.

**Tech Stack:** TypeScript (the app's `tsconfig`), Vite 6 (already installed in `windows/node_modules`), `node:test`, Bash 3.2-compatible scripts (they also run in the Windows runner's Git Bash), Swift through `swiftc` for the render scripts, Python 3 for the patches, `playwright-cli` with its cached browsers for the page checks and screenshots, `sips` for crops and sizes.

**Spec:** `docs/superpowers/specs/2026-10-08-release-prep-design.md` (sub-project D, stage 1, approved by the owner on 2026-10-08): section 5 "The site" and section 4 "Tester notes and feedback" for the content, section 7 "Build order" for this plan's list (**D1-tools**, the other plan, is not part of it), and "Out of scope" and "Done means". Read the whole spec before starting.

**Base:** branch `d1/site`, created from `notchmeow/rebrand` at `940c6fe` **after the small fixes after B have merged** (`docs/superpowers/plans/2026-10-08-small-fixes-after-b.md`). Both plans edit `README.md`: this plan's README anchors are the text after that plan's Task 5, Steps 2 and 2b (Task 0 checks that they are in). **It changes no pixel and no behaviour of either app.** It adds files, the `windows/` entry and config for the site, one line in a render script's compile list (a script, not the app), and edits `README.md`, `docs/THEME.md`, `CLAUDE.md` (with the owner's OK, open question 6) and the Windows tests workflow.

## SUBAGENT RULES

Every subagent and the controller follow these; the controller puts the ones a task needs in its brief (never the whole plan's rules).

- **Never launch, quit or replace a NotchMeow app or the Tauri app.** The render scripts are not the app and may run. Everything else is files, Node tests and a static page in a headless browser.
- **Install and download nothing.** `npx --no-install` only; never `npm install`, `npm run build` or `npm run dev`; `playwright-cli` uses the browsers already cached (never `install-browser`). No `brew`, `pip`, Docker build or pull, or network fetch.
- **In a worktree, `windows/node_modules` is a real APFS clone** (`cp -cR` from the main checkout's `windows/node_modules`, Task 0), never a symlink.
- **Delete with `trash`, never `rm -rf`** (the scripts below clean their own `mktemp` folders; that is the repository's style). Screenshots go outside the repository, in `${TMPDIR:-/tmp}/d1site-shots`; run `playwright-cli` from there, so that its `.playwright-cli` folder never lands in the repository.
- **Stop a server only by the PID saved when it started** (`kill "$(cat server.pid)"`), never with `kill $(lsof ...)` or by port. The static server listens on `127.0.0.1` only. **Close a browser by its session name** (`playwright-cli -s=d1site close`), never with `close-all`. Every server and browser a task starts is stopped before the task ends.
- **Never run the real `claude` binary, never read tokens or credentials, never sign in.** Never write to `~/.claude`, to `~/Library/Logs/NotchMeow` or to NotchMeow's preferences.
- **Every shell block and every `Run:` line passes `bash -n`.** A commit message goes through `git commit -F <file>`. A diff against the branch uses the merge base, `notchmeow/rebrand...HEAD`, never `notchmeow/rebrand`, which moves.
- **Commit only in a task's commit step, and never push.**
- **Subagents are the `nm-*` agents** (Haiku 5.5 first, Sonnet 5.5 only on a CLAUDE.md trigger); the table below says which one runs each task.
- **If a command is denied by a permission prompt, stop and report it.** Do not work around it.

## Review Focus

The spec says what the site must do and is silent on these inputs. Each would bite a visitor, a maintainer or the CI first, most likely first. Each line names its test.

1. **A page that reaches outside in a way a plain search misses:** a tag split over two lines, capital letters (`HTTPS://`, `<A HREF`), an address that starts `//`, a `data:` or `javascript:` value, a look-alike host (`github.com.evil.example`), an `@import`, a `url(` of another host, a `fetch`, a beacon, a cookie or local storage, an `<img>` or `<canvas>` with no text for a reader, the old character's name, Coucou's name outside the credits. Expected: the check fails, names the file and the reason, and a clean site passes. Tests: Task 3, `test-check-site.sh`'s 28 cases (each is one of these), and Task 5's request list from a real browser.
2. **The motion setting and the page's visibility:** reduced motion on, the tab hidden, the cats scrolled out of view, a setting that is the text `"false"` or the number 1 instead of a boolean, a coat swapped or the window resized while the cats hold a still frame. Expected: no frame is scheduled unless the tab is shown, the cats are on screen and motion is allowed, and a still frame is drawn (and redrawn on a swap or a resize). Tests: Task 1 "the cats animate only while…" and "only a real true or false counts…", Task 5 "frames" (counted in a real browser: shown, scrolled away, reduced, hidden).
3. **A phone:** 375 px wide, wide pictures inside narrow cards, a 16-coat row, canvases of any size, a visitor with a finger and no pointer. Expected: no sideways scroll of the page, wide pictures scroll inside their own labelled box, the coat row is four across, a canvas is never drawn at zero size, and a finger lifted sends the cats' gaze back to the front. Tests: Task 5 "phone", Task 6 phone screenshots.
4. **A stale or foreign bundle:** the engine or `shared/theme.json` changes and nobody rebuilds, the build emits a third file, a Windows checkout turns the committed files into CRLF. Expected: `check-site.sh` fails and says how to rebuild; line endings alone do not fail it. Tests: Task 3 "prove that the bundle check bites" and the comparison without carriage returns.
5. **A coat or a cat the visitor should not be able to pick:** a coat that is not one of the 16, `__proto__` or `constructor`, a cat number of 2 or `"1"`, the same coat on both cats, a pick made before the script ran. Expected: nothing changes for a bad pick, both cats may wear the same coat, and without the script the stage and the row stay hidden (the lead text and the buttons stay). Tests: Task 1 "pickCat takes 0 or 1…", "every one of the sixteen coats…", Task 5 "the cats and the coats".

### Task 1: The rules: `windows/src/site/rules.ts`

**Files:**
- Create: `windows/src/site/rules.ts`, `windows/scripts/cat-tests/site.test.mjs`

**Interfaces:**
- Consumes: `CAT_IDS` and `PRESETS` from `windows/src/cat/presets.ts`.
- Produces (Task 2 imports them): `interface PageState { hidden: boolean; inView: boolean; reduced: boolean }`; `animates(p: PageState): boolean`; `interface Hero { coats: [string, string]; picked: 0 | 1 }`; `START: Hero` (`shrimpy` and `momo`, the left cat picked); `pickCat(h: Hero, i: unknown): Hero` (the same object back for a bad index); `pickCoat(h: Hero, id: unknown): Hero` (the same object back for a bad coat); `dressing(h: Hero): string`.

- [ ] **Step 1: Write the failing tests**

```bash
cat > windows/scripts/cat-tests/site.test.mjs <<'EOF_SITE_TEST'
import test from "node:test";
import assert from "node:assert/strict";
import { CAT_IDS, PRESETS } from "../../src/cat/presets.ts";
import { START, animates, dressing, pickCat, pickCoat } from "../../src/site/rules.ts";

test("the cats animate only while the tab is shown, they are on screen and the visitor has not asked for less motion", () => {
  for (const hidden of [false, true]) for (const inView of [false, true]) for (const reduced of [false, true]) {
    assert.equal(animates({ hidden, inView, reduced }), !hidden && inView && !reduced, JSON.stringify({ hidden, inView, reduced }));
  }
});

test("only a real true or false counts: text and numbers never turn the cats on", () => {
  assert.equal(animates({ hidden: "false", inView: true, reduced: false }), false);
  assert.equal(animates({ hidden: false, inView: 1, reduced: false }), false);
  assert.equal(animates({ hidden: false, inView: true, reduced: 0 }), false);
  assert.equal(animates({ hidden: false, inView: true, reduced: undefined }), false);
  assert.equal(animates({}), false);
});

test("the hero starts with Shrimpy on the left, picked, and Momo on the right", () => {
  assert.deepEqual(START, { coats: ["shrimpy", "momo"], picked: 0 });
});

test("pickCat takes 0 or 1 and nothing else", () => {
  assert.equal(pickCat(START, 1).picked, 1);
  assert.equal(pickCat(pickCat(START, 1), 0).picked, 0);
  for (const bad of [2, -1, 0.5, NaN, Infinity, "1", "0", null, undefined, [], {}, true]) assert.equal(pickCat(START, bad), START, String(bad));
});

test("a coat goes to the picked cat only, and the other keeps its own", () => {
  const left = pickCoat(START, "latte");
  assert.deepEqual(left.coats, ["latte", "momo"]);
  const right = pickCoat(pickCat(START, 1), "ginger");
  assert.deepEqual(right.coats, ["shrimpy", "ginger"]);
```

```bash
// What the site's cats decide, as plain data in and out (no DOM), so the plain-Node checks (npm run check:cat) can run it.

import { CAT_IDS, PRESETS } from "../cat/presets.ts";

/** What the page knows about whether its cats can be seen and how much motion the visitor wants. */
export interface PageState { hidden: boolean; inView: boolean; reduced: boolean }

/** Frames are drawn only while the tab is shown, the cats are on screen and the visitor has not asked for less motion: only `true` counts. */
export const animates = (p: PageState): boolean => p.hidden === false && p.inView === true && p.reduced === false;

/** The two cats of the hero: the coat each wears and which of them the coat row dresses. */
export interface Hero { coats: [string, string]; picked: 0 | 1 }
export const START: Hero = { coats: ["shrimpy", "momo"], picked: 0 };

  const coats: [string, string] = [h.coats[0], h.coats[1]];
  coats[h.picked] = id;
  return { ...h, coats };
}
```

```bash
// docs/assets/cats.js and cats.css. The page (docs/index.html) holds the markup; nothing here leaves the page: no request, no storage, no sound.

import type { Hero } from "./rules.ts";

interface Slot { engine: BotEngine; canvas: HTMLCanvasElement; name: HTMLElement; box: HTMLElement; button: HTMLButtonElement }

const dpr = () => Math.min(2, window.devicePixelRatio || 1);

function start(stage: HTMLElement, row: HTMLElement, hint: HTMLElement) {

  let pointer: { x: number; y: number } | null = null;
  addEventListener("pointermove", (e) => { pointer = { x: e.clientX, y: e.clientY }; });
  addEventListener("pointerup", (e) => { if (e.pointerType !== "mouse") pointer = null; });
  document.documentElement.addEventListener("mouseleave", () => { pointer = null; });

    if (css < 2) return;

      const r = s.canvas.getBoundingClientRect(), look = cursorLook(pointer.x - (r.left + r.width / 2), pointer.y - (r.top + r.height * 0.6));
      s.engine.lookX = look.x; s.engine.lookY = look.y;
    } else if (!pointer) { s.engine.lookX = 0; s.engine.lookY = 0; }
    if (dt > 0) s.engine.update(dt);
    s.engine.draw(c, css, css);

  const loop = new VisibleLoop((dt) => slots.forEach((s) => draw(s, dt)), { raf: requestAnimationFrame.bind(window), caf: cancelAnimationFrame.bind(window), visible: () => animates(page) });

  new IntersectionObserver((entries) => { page.inView = entries[entries.length - 1].isIntersecting; sync(); }).observe(stage);
  new ResizeObserver(() => { if (page.reduced) drawStill(); }).observe(stage);

      s.button.setAttribute("aria-pressed", String(hero.picked === i));
      s.box.classList.toggle("is-picked", hero.picked === i);

    hint.textContent = dressing(hero);
    if (page.reduced) drawStill();

    b.title = PRESETS[id].desc ? `${PRESETS[id].label}: ${PRESETS[id].desc}` : PRESETS[id].label;
    cv.setAttribute("aria-hidden", "true"); label.textContent = PRESETS[id].label;
    const w = 56, h = 52, k = dpr();

    const c = cv.getContext("2d")!;
    c.scale(k, k);
    drawCat(c, stillView(PRESETS[id], newPose()), w / 2, h / 2 + 1, 38);
    b.append(cv, label);
    b.addEventListener("click", () => {

      hero = pickCoat(hero, id);
      if (hero === was) return;
      slots[hero.picked].engine.setCoat(id);
      slots[hero.picked].engine.emote("happy");
      show();
    });
    thumbs.set(id, b);
    row.append(b);
  }
  show();
  sync();
}
```

```bash
#!/usr/bin/env bash
# The site's checks (docs/, spec "D stage 1", section 5):
#   1. the committed bundle, docs/assets/cats.js and cats.css, is what a fresh build makes (windows/vite.site.config.ts, into a temporary folder);
#   2. the pages make no request to another host and set nothing on the visitor: no script, style, font or image from outside, no @import, no fetch, no cookie or storage;
#      a link (<a href>) may go to GitHub or to the credits' author; every picture has alt text; the old character's name is nowhere, and Coucou's only in the credits.
#   bash scripts/check-site.sh                              both checks (needs windows/node_modules)
#   SITE_DIR=<folder> bash scripts/check-site.sh --pages-only   only the second, on another folder (scripts/test-check-site.sh does)
set -uo pipefail
cd "$(dirname "$0")/.."
SITE="${SITE_DIR:-docs}"
LINK_HOSTS='github.com|louisraille.fr'   # the hosts an <a href> may name
OLD="mo""chi"                            # the old character's name, in two halves so that no search for it finds this file
fail=0
bad() { echo "✗ $1"; fail=1; }

# A file as one line, so that a tag split over several lines is matched too.
flat() { tr '\r\n\t' '   ' < "$1"; }
# The page without its credits section (the one place the original project is named).
outside_credits() { flat "$1" | awk '{ s = index($0, "<section id=\"credits\""); if (s) { r = substr($0, s); e = index(r, "</section>"); $0 = substr($0, 1, s - 1) substr(r, e + 10) } print }'; }

pages() {
  local f html=0
  for f in "$SITE"/*.html; do [ -f "$f" ] && html=$((html + 1)); done
  [ "$html" -ge 2 ] || bad "$SITE has fewer than two pages (index.html and testers.html)"
  for f in "$SITE"/*.html "$SITE/site.css" "$SITE/assets/cats.js" "$SITE/assets/cats.css"; do
    [ -f "$f" ] || { bad "$f is missing"; continue; }
    local t; t="$(flat "$f")"
    # Anything that loads or sends something from another place.
    grep -q '@import' <<< "$t" && bad "$f: @import"
    grep -qiE 'url\([[:space:]]*["'"'"']?[[:space:]]*(https?:|//)' <<< "$t" && bad "$f: url() of another host"
    grep -qE '(^|[^A-Za-z0-9_])(fetch|importScripts)[[:space:]]*\(|XMLHttpRequest|sendBeacon|WebSocket|EventSource' <<< "$t" && bad "$f: a network call (fetch, XMLHttpRequest, sendBeacon, WebSocket, EventSource or importScripts)"
    grep -qE 'document\.cookie|localStorage|sessionStorage|indexedDB' <<< "$t" && bad "$f: a cookie or browser storage"
    # The old character's name is nowhere; Coucou's only in the credits section of a page.
    grep -qi "$OLD" <<< "$t" && bad "$f: the old character's name"
    case "$f" in
      *.html)
        grep -qi 'coucou' <<< "$(outside_credits "$f")" && bad "$f: Coucou's name outside the credits section"
        # Every tag but <a> may not point anywhere but into docs/: no http, https, //, data or javascript value.
        local tag href host
        while IFS= read -r tag; do
          case "$tag" in
            "<a "*) ;;
            *) grep -qiE '=[[:space:]]*["'"'"']?[[:space:]]*(https?:|//|data:|javascript:)' <<< "$tag" && bad "$f: a tag that loads from outside: ${tag:0:90}" ;;
          esac
        done < <(grep -oiE '<[a-z][^>]*>' <<< "$t")
        # A link may name only the allowed hosts.
        while IFS= read -r href; do
          href="${href#*=}"; href="${href#[[:space:]]}"; href="${href#[\"\']}"; href="${href%%[\"\' >]*}"
          href="$(printf '%s' "$href" | tr 'A-Z' 'a-z')"
          case "$href" in
            http://*|https://*|//*)
              host="${href#*//}"; host="${host%%[/?#]*}"
              grep -qE "^(www\.)?($LINK_HOSTS)$" <<< "$host" || bad "$f: a link to $host" ;;
            javascript:*|data:*) bad "$f: a link that runs or embeds: ${href:0:40}" ;;
          esac
        done < <(grep -oiE '<a [^>]*>' <<< "$t" | grep -oiE 'href[[:space:]]*=[[:space:]]*("[^"]*"|'"'"'[^'"'"']*'"'"'|[^ >]+)')
        grep -qiE '<(iframe|embed|object|form|video|audio|source|track|frame)[ >]' <<< "$t" && bad "$f: an element that embeds or collects (iframe, embed, object, form, video, audio, source, track, frame)"
        # Pictures: an <img> has alt text, a <canvas> a label or is hidden from readers.
        while IFS= read -r tag; do
          grep -qiE 'alt[[:space:]]*=[[:space:]]*"[^"]+"' <<< "$tag" || bad "$f: a picture without alt text: ${tag:0:90}"
        done < <(grep -oiE '<img[ >][^>]*>?' <<< "$t")
        while IFS= read -r tag; do
          grep -qiE 'aria-label[[:space:]]*=[[:space:]]*"[^"]+"|aria-hidden[[:space:]]*=[[:space:]]*"true"' <<< "$tag" || bad "$f: a canvas without a label: ${tag:0:90}"
        done < <(grep -oiE '<canvas[ >][^>]*>?' <<< "$t")
        grep -qiE 'name="viewport"' <<< "$t" || bad "$f: no viewport meta (the page must work on a phone)"
        ;;
      *)
        grep -qi 'coucou' <<< "$t" && bad "$f: Coucou's name"
        # In a script or a style sheet no address at all: nothing is fetched, and nothing points away.
        grep -qiE 'https?://' <<< "$t" && bad "$f: an address (http:// or https://)"
        ;;
    esac
  done
  [ "$fail" -eq 0 ] && echo "✓ $SITE: no outside request, no cookie, alt text everywhere, the names as they should be"
}

bundle() {
  [ -d windows/node_modules ] || { bad "windows/node_modules is missing: run npm ci in windows/"; return; }

  fi

    # Compared without carriage returns, so a Windows checkout's line endings do not matter.
    if [ -f "$tmp/out/$f" ] && [ -f "docs/assets/$f" ] && cmp -s <(tr -d '\r' < "$tmp/out/$f") <(tr -d '\r' < "docs/assets/$f"); then :
    else bad "docs/assets/$f is not what a fresh build makes: run  cd windows && npx --no-install vite build --config vite.site.config.ts  and commit it"; fi
  done
  rm -rf "$tmp"
  [ "$fail" -eq 0 ] && echo "✓ docs/assets/cats.js and cats.css are what a fresh build makes"
}

case "${1:-}" in
  --pages-only) pages ;;
  "") bundle; pages ;;
  *) echo "usage: bash scripts/check-site.sh [--pages-only]" >&2; exit 2 ;;
esac
exit "$fail"
EOF_CHECK_SITE
```
