Older tester builds

Thank you for trying NotchMeow. The tester builds were private files, version 0.9.x, that I checked on my own machines first. They are not signed, so your system asks you once before it opens one. This page says what to click.

Nothing is collected. There is no feedback button and no telemetry: you tell me what you found in the message where we already talk.

Older builds. Version 1.0.0 is the public release, and it replaces these tester builds. Download it from the home page.

Install

macOS (15 or later)

  1. Open the file you were given. A .zip: unzip it. A .dmg: double-click it. Either way, drag NotchMeow to Applications, then open it. macOS refuses it once, because it isn't notarized yet.
  2. Open System Settings, then Privacy & Security, scroll down to the message about NotchMeow and click Open Anyway. Confirm.
  3. Updating to a later tester build: replace the app. macOS then asks once whether the new build may read NotchMeow's saved keys, because an unsigned build's identity changes with every build. Answer Always Allow.

Windows (10 or 11)

  1. Put notchmeow.exe and notchmeow-hook.exe side by side in one folder. There is no installer. The two files must stay together, because the Claude Code hooks look for the hook file next to the app.
  2. Double-click notchmeow.exe. SmartScreen says "Windows protected your PC": click More info, then Run anyway.
  3. Windows Defender may flag the files, because these builds are not signed. If it does, tell me.

Linux

  • AppImage: make it executable with chmod +x, then run it.
  • Debian and Ubuntu: sudo apt install ./NotchMeow-….deb
  • Fedora: sudo dnf install ./NotchMeow-….rpm
  • On GNOME the island is a plain always-on-top window, not an overlay at the top edge.

Uninstall

  1. Remove the Claude Code hooks first: open NotchMeow's Settings, find the Claude Code hooks and click Uninstall (Uninstall hooks… on Windows and Linux). That takes NotchMeow out of ~/.claude/settings.json.
  2. Then delete the app: drag it to the Trash on the Mac, delete the two files on Windows, and on Linux delete the AppImage or remove the package with your package manager.

What to try

  • Install the Claude Code hooks from Settings. NotchMeow backs up ~/.claude/settings.json and shows you the diff first.
  • Run a Claude Code session and approve a permission from the notch.
  • Answer a question Claude Code asks you.
  • Drop a file on the notch.
  • Pick a coat, a motion style, a personality and a display mode in Settings, then Cat.
  • Start a subagent and watch for its kitten.
  • Leave it idle for ten minutes and watch the cat fall asleep.
  • On the Mac, play some music and watch the cat dance.

What to tell me

  • Your computer and its system version.
  • NotchMeow's version: the number in the name of the file you were given.
  • What you tried.
  • What happened, and what you expected.
  • A screenshot, if it helps.

A cat that looks wrong, a sound you don't like and a moment that felt slow are all worth telling me.
